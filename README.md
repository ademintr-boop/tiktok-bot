# 🤖 Автономный ИИ-блогер для TikTok

Работает целиком в облаке (GitHub Actions), ваш ПК не нужен. Настроить всё можно из браузера, даже с телефона.

**Что делает бот при каждом запуске:**

1. Обновляет статистику канала (просмотры, лайки, комментарии, репосты, подписчики).
2. Выбирает тему: чаще те, что набирают больше, но иногда пробует новые.
3. Пишет сценарий через Claude, учитывая удачные и слабые ролики, и не повторяет прошлые сюжеты.
4. Озвучивает текст нейроголосом (edge-tts, бесплатно).
5. Делает субтитры: крупные слова с подсветкой текущего, плюс заголовок-крючок в начале.
6. Подбирает вертикальные фоновые видео с Pexels (без ключа будет анимированный градиент).
7. Собирает MP4 1080×1920 (30 fps, H.264 + AAC) через ffmpeg.
8. Публикует видео через официальный TikTok Content Posting API с меткой «Создано ИИ».
9. Сохраняет историю в `data/` и отчёт в `reports/latest.md`.

Расписание: 2 ролика в день (09:17 и 18:47 по Стамбулу) и сбор статистики раз в день. Время меняется в `.github/workflows/publish.yml`.

## Настройка (≈30 минут, один раз)

### 1. Репозиторий на GitHub
- Создайте аккаунт на github.com и новый репозиторий (например, `tiktok-bot`).
- Загрузите в него файлы проекта: **Add file → Upload files**. Папку `.github` перетащите тоже, без неё не будет расписания.

### 2. Ключи
| Что | Где взять | Цена |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys | несколько центов за ролик |
| `PEXELS_API_KEY` (по желанию) | pexels.com/api | бесплатно |

### 3. Страница для авторизации (GitHub Pages)
- **Settings → Pages → Branch: `main`, папка `/docs` → Save.**
- Адрес приёмника будет таким: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/callback.html`
- **Settings → Secrets and variables → Actions → Variables** → создайте переменную `TIKTOK_REDIRECT_URI` с этим адресом.

> На бесплатном тарифе GitHub Pages работает только для публичных репозиториев. Секреты при этом всё равно никто не видит. Если нужен приватный бот, создайте отдельный публичный репозиторий только с `callback.html`.

### 4. Приложение TikTok для разработчиков
1. На developers.tiktok.com создайте приложение (**Manage apps → Connect an app**).
2. Добавьте продукты **Login Kit** и **Content Posting API**, а в Content Posting API включите **Direct Post**.
3. Включите scopes: `user.info.basic`, `user.info.stats`, `video.list`, `video.publish`.
4. В Login Kit укажите Redirect URI из шага 3.
5. Скопируйте **Client key** и **Client secret**.

Начать можно в режиме **Sandbox**: добавьте свой аккаунт в *Target users*.

### 5. Токен GitHub для самообновления
Он нужен, чтобы бот сам сохранял новый токен TikTok.
- github.com → Settings → Developer settings → **Fine-grained tokens** → Generate.
- Repository access: только этот репозиторий. Permissions → **Secrets: Read and write**.

### 6. Секреты
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
`ANTHROPIC_API_KEY`, `PEXELS_API_KEY`, `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, `GH_PAT`

### 7. Подключение TikTok-аккаунта
1. Откройте **Actions → 🔑 Авторизация TikTok → Run workflow** с пустым полем. В отчёте запуска появится ссылка.
2. Откройте её, войдите в TikTok и разрешите доступ. Страница покажет код, скопируйте его.
3. Снова запустите **Run workflow** и вставьте код. Бот сам создаст секрет `TIKTOK_REFRESH_TOKEN`.

### 8. Проверка
- В `config.yaml` поставьте `publish.enabled: false` и запустите **🎬 Публикация ролика** вручную.
- Готовый MP4 появится во вкладке запуска (Artifacts), можно скачать и посмотреть.
- Если всё нравится, верните `enabled: true`. Дальше бот работает сам.

## ⚠️ Важно знать

- **Пока приложение TikTok не прошло аудит, все видео публикуются как приватные (SELF_ONLY).** Так устроен сам TikTok. Чтобы ролики были видны всем, подайте приложение на аудит Direct Post в кабинете разработчика (обычно занимает несколько недель). До этого можно вручную открывать видео в приложении TikTok.
- У TikTok есть лимит публикаций через API (обычно около 15 в сутки на аккаунт). В боте стоит ограничение `max_posts_per_day: 3`.
- Видео помечается как созданное ИИ (`is_aigc: true`), а в подписи стоит «Вымышленная история». Это требование правил TikTok, отключать не стоит.
- TikTok понижает в выдаче однотипный массовый контент. Меняйте нишу, темы и голос в `config.yaml` и добавьте свою музыку (без нарушения авторских прав) в `assets/music/`.
- Refresh-токен TikTok действует до года. Если в отчёте появилась ошибка авторизации, повторите шаг 7.

## Как управлять ботом
| Задача | Где |
|---|---|
| Ниша, темы, хэштеги, голос, длина | `config.yaml` |
| Расписание | `.github/workflows/publish.yml` (время в UTC) |
| Отчёт со статистикой | `reports/latest.md` и сводка каждого запуска в Actions |
| Все ролики и их цифры | `data/history.json` |
| Выключить бота | Actions → workflow → **Disable workflow** |

## Структура
```
bot/story.py      сценарий (Claude API)
bot/voice.py      озвучка + тайминги слов (edge-tts)
bot/subtitles.py  субтитры ASS/SRT
bot/visuals.py    фоны (Pexels / градиент)
bot/render.py     сборка MP4 (ffmpeg)
bot/tiktok.py     OAuth, публикация, статистика (официальный API)
bot/analytics.py  анализ, выбор темы, отчёт
bot/main.py       запуск: run | analytics | auth-url | auth-exchange | demo
```
